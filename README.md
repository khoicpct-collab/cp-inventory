# CHECKSTOCK KIEU - Hệ Thống Quản Lý Kho C.P.CT

Hệ thống quản lý kho thông minh tích hợp Google Sheets với giao diện web hiện đại.

## 🌟 Tính năng nổi bật

- 📊 **Quản lý tồn kho** theo ngày (01-31)
- 📈 **Phân tích tuổi tồn kho** tự động
- 🔄 **Đồng bộ thời gian thực** với Google Sheets
- 📱 **Responsive design** trên mọi thiết bị
- 📤 **Xuất Excel** toàn bộ dữ liệu
- 🎯 **Bộ lọc đa chiều** thông minh
- ⚡ **Tốc độ cao** với JavaScript hiện đại
- 🔒 **Kết nối an toàn** với Google Apps Script

## 🚀 Cài đặt & Triển khai

### Yêu cầu hệ thống
- Node.js >= 18.0.0
- NPM >= 9.0.0
- Google Account (cho Google Sheets)

### Cài đặt local

```bash
# Clone repository
git clone [repository-url]
cd checkstock-kieu

# Cài đặt dependencies
npm install

# Chạy local server
npm start
